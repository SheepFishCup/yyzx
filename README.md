# 一、总体架构

颐养中心（yyzx）
## 1. 项目概述
#### 项目背景：

​		东软颐养中心是一个为老年人提供集体居住及配套服务的系统，涵盖入住管理、床位管理、护理管理、健康管家等多个功能模块，旨在提高老年人晚年生活的身心健康和生活质量。项目采用全栈开发流程，从框架搭建到设计开发，实现了 Spring Boot 后端接口与 Vue 前端页面及功能的完整开发。系统支持浏览器在线操作，无需安装且操作方便，具有良好的可扩展性，后续可拓展用药管理、健康档案等功能

#### 目标用户：

  医疗/养老机构工作人员（如护士、管理员）
  客户（入住人员）
  系统管理员

**后端技术：Spring Boot2+MySQL+MyBatis-Plus+Druid+Lombok+Swagger2+JWT+Maven**

**前端技术：vue3+Element-UI+Axios**

**开发工具:  IDEA, Maven, MySQL8.0, Navicat, Git, Vue-cli，Vscode**

### 项目构建与部署

- **构建工具**：Maven，管理项目依赖和构建流程

- **热部署**：Spring Boot DevTools，支持开发时自动重启

- **打包插件**：Spring Boot Maven Plugin，将应用打包为可执行 jar

  

## 2.核心功能模块

1. **客户管理**：包括入住登记、退住登记、外出登记、膳食日历维护等

2. **床位管理**：床位示意图展示、床位调换及使用详情管理

3. **护理模块**：护理项目设置、护理级别定义、客户护理配置及护理记录管理

4. **健康管家**：服务对象设置、客户购买的护理服务管理及日常护理信息录入

5. **用户管理**：系统用户基础信息维护

   

## 3.数据库设计

系统数据库包含 18 张核心表，主要包括：

- `user`：存储用户信息
- `bed`：存储房间床位信息
- `customer`：存储客户信息
- `nursecontent`：存储护理内容信息
- `nurserecord`：存储护理记录信息
- `outward`：存储外出登记信息
- `backdown`：存储退住登记信息
