# 颐养中心管理系统（yyzx）

> 东软颐养中心 —— 面向养老机构的综合服务管理平台

## 📖 项目简介

东软颐养中心是为老年人提供集体居住及配套服务的综合管理系统，涵盖入住管理、床位管理、护理管理、健康管家等多个功能模块，旨在提高老年人晚年生活质量。

项目采用全栈开发模式，实现 Spring Boot + Vue3 前后端分离架构，具备良好的可扩展性，后续可拓展用药管理、健康档案等功能。

## 👥 目标用户

- 医疗/养老机构工作人员（护士、管理员）
- 入住客户
- 系统管理员

## ✨ 项目亮点

### 1. 安全体系
- JWT Token 身份认证
- 图片验证码 + **5次失败锁定**机制
- BCrypt 加密用户密码
- 邮件验证覆盖密码重置流程
- WebSocket 实时推送登录通知

### 2. 缓存与性能优化
- Redis + Spring Cache 缓存护理级别等热点数据
- 分布式锁 + **随机过期时间**，防止缓存击穿与雪崩
- SQL优化（EXISTS 替换子查询）+ 索引优化
- **客户信息查询响应：165ms → 69ms，TPS 达 447**

### 3. 分布式与异步处理
- Redisson 实现分布式锁，保证账号数据一致性
- RabbitMQ 异步处理入住通知，通过钉钉机器人推送消息
- Quartz 分布式任务调度（替代 Spring Task），支持多实例部署

### 4. 前后端协作
- 动态路由加载
- 请求防抖优化
- 文件上传（multipart/form-data）
